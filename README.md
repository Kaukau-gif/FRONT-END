# 🎨 Estudos de Front-end: CSS Box Model

Exercício da primeira aula de front-end do curso de Análise e Desenvolvimento de Sistemas. A página demonstra o **Box Model** do CSS (margem, borda, preenchimento e conteúdo) com caixas, uma imagem de destaque e um bloco com fundo em degradê.

## Conceitos praticados

- Estrutura semântica em HTML
- Box Model: `margin`, `border`, `padding` e `width`
- Degradê com `linear-gradient`
- Imagem de fundo

## Como ver

Abra o arquivo `index.html` no navegador.
